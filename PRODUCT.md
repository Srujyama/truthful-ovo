## Product Purpose
Track what is owed, the net economics of changed terms, and whether an exact action remains authorized. Connect a vendor promise to evidence of fulfillment. Preserve original terms and authority, calculate remaining value in integer cents, and make each financial result inspectable.

## Capabilities and Constraints
Execution lab explores bounded multi-agent program orderings with the actual financial reducer, exposes shortest unsafe-effect witnesses under a deliberately naive cached-check reference, and replays the same program through guarded execution. Resource exhaustion stays inconclusive. Explicit deterministic repairs preserve authority and report completion separately; custom programs do not receive invented repairs.

Signed authority is a custom Ed25519 profile: exact action and complete approval binding, key-possession, narrowed child delegation, expiry/revocation, root one-use consumption atomically committed with the local financial effect, durable retries, reset invalidation and signed lifecycle/receipt export. The offline verifier requires a separately pinned public trust root. Browser authority is a separate isolated ephemeral workspace; local server mode uses SQLite. No production identity, AP2/UCP conformance, global formal proof, source authenticity, current offline revocation, or external settlement is implied.

A multi-case assurance portfolio conserves credit capacity globally. Issued, applied, reversed and conditional value remain separate. Versioned amendments require conflict resolution, exact approval and local execution; effective dates and knowledge cutoffs replay independently. Approval binds material revision, source revisions and policy. Explicit renewal baselines expose incremental cost and net value. The evidence graph derives from actual state; nine executable failure cases expose rejected commands. Each selected commitment, including a supported import, has its own original-action review path. Exact bound source revisions open within that review and return to the same action. Role-specific affordances explain disabled writes, and an actual import preflight preserves navigation to already-tracked records for every role. Demo identities are selectable, not production authentication. No external transaction is executed.

Evidence lab accepts supported promise text, positive applied-credit ledger CSV, and optional vendor reply. Exact vendor, USD, commitment reference and date checks; explicit provenance verification; duplicate handling; source quote offsets; review instead of unsupported claims. Future/originally conditional promises and unknown replies cannot produce an approved recovery draft. A later conditional reply does not amend the original promise. Up to thirty browser-local case snapshots; exact-draft approval; unsent EML, CSV and JSON evidence exports. Hash-linked records establish internal consistency, not external authenticity.
