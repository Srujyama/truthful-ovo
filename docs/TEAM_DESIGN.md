The local isolated reference preview blocks non-GET requests and all API paths. Its replay is reference data, not an integration into this application. No reference provider scripts, credentials or paid calls are used.

Nomen's implementation and artwork have not been copied into the product. The team renderer is original code. The local study notes source inspection separately from operated browser behavior. Prior renderer/scene acceptance does not approve this new direction.
